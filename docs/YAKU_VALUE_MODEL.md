# 役价值判断机制

## 1. 设计目标

未听牌时无法用 `HandEvaluator` 精确得知最终会形成什么役，因为后续摸牌、切牌和鸣牌都还未知。当前机制因此估计的是“役路线潜力”，而不是声称给出真实和牌概率。

役价值模块遵循三个原则：

1. 只使用玩家当前可见的信息；
2. 比较动作前后变化，不给所有候选重复添加同一份绝对奖励；
3. 保存原始概率、预计番数、证据和分数贡献，以便后续训练或替换算法。

## 2. 模块位置

- `baseline/yaku.py`：役状态、单役评估和动作前后比较；
- `baseline/config.py`：役参数严格加载；
- `configs/baseline.yaml`：概率和线性权重；
- `baseline/features.py`：将役价值差加入候选特征；
- `baseline/decision.py`：在决策记录中保存动作前后役明细。

`YakuPotentialEvaluator` 不选择动作，它只返回可训练特征。最终选择仍由通用线性评分器完成。

## 3. 数据结构

每种役返回：

```text
YakuEvaluation
├── yaku          役路线名称
├── state         impossible / possible / likely / guaranteed / complete
├── probability   启发式成立概率，范围0～1
├── expected_han  概率加权后的预计番数
├── potential     提供给动作比较的标准化潜力
└── evidence      形成判断的可读证据
```

每个切牌动作同时保存 `before`、`after` 和各役的潜力差：

```text
yaku_delta = potential_after - potential_before
```

总评分中的贡献为：

```text
yaku_score = yaku_delta × yaku_weight
```

这样切掉最后一张幺九会提高断幺潜力；切掉役牌对子的一张会降低役牌潜力；与某条役路线无关的切牌不会凭空获得奖励。

## 4. 当前覆盖的役路线

### 4.1 役牌

覆盖：

- 白、发、中；
- 场风；
- 自风；
- 场风与自风重叠产生的连风牌两番。

当前估值：

```text
刻子：100%计入对应番数
对子：对应番数 × pair_probability
单张：对应番数 × single_probability
```

默认对子概率为0.55，单张概率为0.12。东场东家的东对子因此得到 `2 × 0.55 = 1.10` 的预计番数，而不是被集合去重成一番。

这仍是潜力估计，没有根据剩余可见牌数修正碰出概率；该项可在后续加入。

### 4.2 断幺九

统计手牌中的幺九牌和字牌：

```text
probability = max(0, 1 - forbidden_count × penalty)
```

每切掉一张幺九牌，断幺潜力会上升。如果已经有含幺九的固定副露，断幺立即标记为 `IMPOSSIBLE`。

当前算法没有区分孤张幺九和已经形成面子的幺九；以后应给拆解完成面子设置更高成本。

### 4.3 七对子

已经副露时直接标记为不可能。门清时计算七对子专用向听数：

```text
chiitoi_shanten = 6 - pair_count + max(0, 7 - unique_tile_count)
```

再根据向听数映射成立概率：

| 七对子向听 | 默认概率 |
|---:|---:|
| 0 | 1.00 |
| 1 | 0.75 |
| 2 | 0.45 |
| 3 | 0.20 |
| 更远 | 0.08 |

七对子固定二番，因此预计番数为 `2 × probability`。拆掉对子通常会产生负的七对子价值差。

### 4.4 混一色/清一色

分别以万、筒、索为候选主色，统计：

- 主色牌数量；
- 字牌数量；
- 异色牌数量；
- 已固定副露是否包含不兼容花色。

每门分别估计混一色和清一色潜力，并只保留价值更高的路线。混一色按门清3番、开放2番；清一色按门清6番、开放5番计算。

如果已有异色副露，该花色路线直接被排除。切掉异色牌会提高染手潜力，切掉主色牌通常会降低潜力。

为了避免重复计算，`flush` 只输出混一色与清一色中的最佳一条，不把两者相加。

## 5. 与原有评分的关系

当前切牌总分包含：

```text
向听数
+ 有效牌枚数与种类
+ 基础搭子和对子
+ 宝牌、赤牌保留价值
+ 孤张价值
- 放铳风险
+ 役牌潜力变化
+ 断幺潜力变化
+ 七对子潜力变化
+ 染手潜力变化
```

役价值不会覆盖向听数：退一向听仍然有极大的基础惩罚。它主要用于同向听、有效牌接近的候选之间进行方向选择。

## 6. 配置参数

角色成立概率和路线惩罚位于 `yaku` 配置段；各路线对总分的影响位于 `weights`：

```yaml
weights:
  yaku_yakuhai_delta: 300.0
  yaku_tanyao_delta: 300.0
  yaku_chiitoitsu_delta: 300.0
  yaku_flush_delta: 300.0
```

配置加载器会拒绝未知或缺失字段，概率必须位于0到1。训练时可以只修改这些配置，不改决策代码。

## 7. 决策解释

如果动作让某条路线的潜力变化超过0.01，候选解释中会加入：

```text
tanyao役潜力+0.22
yakuhai役潜力-0.43
flush役潜力+0.31
```

完整结构化结果保存在：

```python
engine.last_decision.candidates[i].yaku_before
engine.last_decision.candidates[i].yaku_after
```

因此以后界面可以显示概率变化、预计番数和判断证据，而不必重新运行评估。

## 8. 当前限制

- 概率是启发式分数，不是经过牌谱校准的真实概率；
- 未结合各类有效牌的实际剩余枚数；
- 未直接计算动作导致的最终期望点数；
- 未覆盖平和、对对和、三色同顺、一气通贯和全带类役；
- 未处理多个役之间更复杂的相关性；
- 断幺尚未区分孤张幺九与固定牌组；
- 染手估值尚未考虑被读牌和防守能力下降；
- 听牌阶段仍应通过 `HandEvaluator` 枚举等待并计算精确打点。

## 9. 推荐后续顺序

1. 使用公开可见枚数修正役牌对子升级概率；
2. 听牌时使用 `HandEvaluator` 替代潜力估计；
3. 加入平和、对对和、三色同顺和一气通贯；
4. 保存全部候选到训练数据；
5. 用高质量牌谱拟合各概率参数和线性权重；
6. 用模拟对战的平均顺位和局收支做第二阶段优化。
