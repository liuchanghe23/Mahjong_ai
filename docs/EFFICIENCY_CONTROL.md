# 纯牌效对照模型

## 1. 用途

`EfficiencyEngine` 是用于评估 BaselineEngine 附加功能是否有效的受控对照。它不是随机模型，而是一个具备基本立直麻将常识、但只按牌效率切牌的确定性模型。

Baseline与Efficiency使用相同的闭合手策略：

- 可以荣和和自摸；
- 听牌后默认立直；
- 立直声明舍牌必须保持听牌；
- 正式立直后严格摸切；
- 允许等待不变的立直后暗杠；
- 不吃、不碰，不主动进行开放杠；
- 响应鸣牌机会时选择跳过。

因此两者主要差异集中在普通切牌评价，而不是和牌或鸣牌政策。

## 2. 切牌依据

每个合法切牌计算：

1. 切牌后的向听数；
2. 有效牌剩余枚数；
3. 有效牌种类数；
4. MJAI动作字符串，仅用于完全同分时稳定排序。

候选按以下字典序选择：

```text
向听数越低越好
→ 有效牌剩余枚数越多越好
→ 有效牌种类越多越好
→ MJAI字符串排序保证确定性
```

等价排序键：

```python
(
    shanten,
    -ukeire_count,
    -ukeire_types,
    action_mjai,
)
```

## 3. 明确不使用的特征

EfficiencyEngine不会读取：

- 役牌、断幺、七对子、染手等役潜力；
- 宝牌和赤牌价值；
- 两面、嵌张、边张等额外牌形分；
- 孤张位置价值；
- 对手立直和放铳风险；
- 点棒、顺位和巡目；
- Baseline的可训练线性权重。

它复用公开状态解析与有效牌计算函数，但只读取向听数和有效牌字段。

## 4. 与Random的区别

RandomEngine可能：

- 放弃和牌；
- 不立直；
- 随机拆掉完成搭子；
- 在同一状态做出不同质量的动作。

因此Random只适合验证系统闭环。EfficiencyEngine才是判断役价值、宝牌价值和危险度是否带来提升的合理基线。

## 5. 推荐评测

```powershell
.\.venv\Scripts\python scripts\evaluate.py `
  --engine baseline `
  --opponent efficiency `
  --matches 1000 `
  --base-seed 20000
```

重点观察：

- 平均顺位和平均收支；
- 和牌率是否因追役下降；
- 平均和牌收入是否提高；
- 放铳率是否因危险度特征下降；
- 样本是否足够大以及验证种子上方向是否一致。

如果Baseline只提高打点却显著降低和牌率，需要降低役价值或宝牌权重；如果放铳率没有改善，说明当前基础危险度还不足以影响实际选择。
