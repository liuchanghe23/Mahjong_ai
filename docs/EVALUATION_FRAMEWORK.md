# 固定种子测评统计框架

## 1. 目标

测评框架用于回答“修改后的模型是否真的更好”，并保证不同版本使用相同牌山和座位轮换规则。它同时支持单模型自测与两个模型直接对战。

## 2. 推荐模式：2对2比较

四人局中每个模型占两个席位：

框架循环遍历四个座位中任选两个的全部6种组合。这样A既会与同组模型相邻，也会与同组模型对家，并且完整周期内占据每个座位的次数相同。两组模型处于同一牌山中，因此平均顺位和收支具有直接比较意义。

仅让四家使用同一模型时，平均顺位由于对称性必然接近2.5，只适合检查稳定性、速度和绝对行为率，不适合证明模型强弱。

## 3. 固定种子

测试种子为连续序列：

```text
base_seed, base_seed + 1, ..., base_seed + match_count - 1
```

相同引擎版本、配置和种子应产生相同动作与牌局结果。决策耗时会受到系统负载影响，不要求完全相同。

## 4. 指标定义

### 顺位指标

- 一至四位次数和比例；
- 平均顺位；
- 平均玩家样本点数收支。

### 进攻指标

- 和牌次数；
- 自摸次数；
- 荣和次数；
- 每玩家局和牌率；
- 平均和牌收入。

### 风险指标

- 放铳次数；
- 每玩家局放铳率；
- 平均放铳损失。

### 行为指标

- 立直次数及每玩家局立直率；
- 决策次数；
- 平均和最大单步决策耗时。

指标中的“局”是玩家局：一轮四人麻将产生四个玩家局样本。使用玩家局作为分母，可以直接比较和牌率和放铳率。

## 5. 流局听牌的限制

RiichiEnv 当前生成的 `ryukyoku` MJAI事件包含原因与点差，但不包含四家公开手牌或独立听牌标记。

荒牌流局时：

- 点差为正的玩家可以确定听牌；
- 点差为负的玩家可以确定未听；
- 四家全听或四家全不听时点差均为0，无法从日志区分。

框架将这种情况记录为 `draw_tenpai_unknown`，不会把它强行算成听牌或未听。若以后需要精确流局听牌率，应扩展模拟器事件，显式写入 `tenpai` 数组。

## 6. 点数统计口径

和牌收入采用 `hora.deltas[winner]`，因此包含本场和当次事件结算中的供托影响。放铳损失采用目标玩家点差的绝对值。

责任支付等特殊情况可能存在多个付款来源；框架仍把 `target` 计为放铳者，但点差按事件实际结果统计。

## 7. 决策耗时

计时范围仅覆盖：

```python
engine.act(observation)
```

不包含 RiichiEnv 状态推进、日志解析和报告写入。每位玩家分别累积次数、总耗时和最大耗时，再聚合到模型级别。

## 8. 运行方式

Baseline与Random直接对战：

```powershell
.\.venv\Scripts\python scripts\evaluate.py `
  --engine baseline `
  --opponent random `
  --matches 1000 `
  --base-seed 10000
```

Baseline四家自测：

```powershell
.\.venv\Scripts\python scripts\evaluate.py `
  --engine baseline `
  --opponent none `
  --matches 1000
```

输出目录默认为：

```text
artifacts/evaluation/
```

每次运行生成：

- JSON：完整机器可读指标、种子、原始计数和逐场双方团队指标；
- Markdown：适合人工查看和版本对比的指标表，以及配对差值的95% Bootstrap置信区间。

对比模式默认按“对局”进行10,000次配对重采样。平均顺位、四位率、点差、和牌率和放铳率的差值方向已统一为正数代表命令中前一个模型更优。可通过`--bootstrap-samples`和`--bootstrap-seed`控制重复次数与统计随机种子。

使用不同基线配置对战时，可分别传入`--config`和`--opponent-config`。完整的批量消融流程见`docs/ABLATION_EXPERIMENTS.md`。

## 9. 建议的版本评估流程

1. 固定一组至少1000个开发种子；
2. 当前稳定版与候选版进行2对2比较；
3. 检查平均顺位、收支、和牌率和放铳率；
4. 使用另一组从未调参使用的验证种子复测；
5. 只有开发集和验证集方向一致时才接受新权重；
6. 保存配置文件、代码版本和JSON报告。

若权重是根据固定开发种子反复调出的，只在同一批种子上提升可能是过拟合，不能视为真实增强。
